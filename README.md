# Flow

Слушайте музыку с друзьями — синхронно, секунда в секунду. Приложение для Windows 10/11.

**Сайт:** https://lucrix1337.github.io/flow/
**Скачать:** [Flow-Setup.exe](https://github.com/Lucrix1337/flow/releases/latest/download/Flow-Setup.exe)

- комнаты по коду, общий плейлист и чат
- синхронизация до миллисекунд
- поиск «название + Enter», «Моя волна», импорт лайков из Яндекс Музыки и SoundCloud
- обычный плеер без комнаты, медиаклавиши, автообновления

Windows может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

Смайлики на сайте и в приложении — [Noto Emoji](https://github.com/googlefonts/noto-emoji) (SIL OFL 1.1).
